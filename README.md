The Student Grade Calculator System is a modular software application engineered to record subject-wise scores, evaluate aggregate performance metrics, derive percentage-based grades, and output official evaluation results.

An automated Python-based evaluation tool that processes academic subject scores to calculate total marks, percentage performance, assigned grades, and overall pass/fail status[cite: 1, 2].

## 🛠️ Technologies Used

- **Programming Language**: Python 3 (Pure Python with standard library)[cite: 1, 2]
- **Core Concepts**:
  - Modular Programming (Separation of Concerns across dedicated modules)[cite: 2]
  - Conditional Logic & Decision Making[cite: 1]


### Execution Steps
1. Clone the repository to your local machine.
2. Open your terminal or command prompt in the project root directory.
3. Run the main entry file using Python:
   
   Execute `python main.py` or `python3 main.py` depending on your environment setup.
